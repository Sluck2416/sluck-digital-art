# Sluck — Digital Art Portfolio

Single-page cinematic portfolio for Sluck, a digital artist based in Bengaluru.

## Files
- `index.html` — the whole site (HTML, CSS and JavaScript in one file)
- `art/` — artwork images used by the gallery

## Deploy on Vercel
1. Push this repo to GitHub.
2. In Vercel, click **Add New → Project** and import the repo.
3. Framework preset: **Other**. No build command, no output directory.
4. Click **Deploy**. Vercel serves `index.html` at the root.

The page loads GSAP from cdnjs.cloudflare.com and fonts from Google Fonts, so it needs internet access.
